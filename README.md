# 酒桌游戏合集

一个为 NAS 环境设计的酒桌游戏集合 Web 应用，支持摇骰子、猜数字等多种游戏，无需登录，开箱即用。

## 项目特点

- **极简设计**：单页面多游戏集成，无需跳转
- **无需登录**：所有用户匿名使用
- **本地存储**：使用浏览器 LocalStorage 实现历史记录
- **响应式布局**：适配手机、平板和桌面端
- **离线可用**：纯前端实现，无需联网

## 支持的游戏

- 摇骰子（支持自定义骰子数量）
- 猜数字（系统随机生成数字，提示大小）
- 预留扩展接口，可添加更多游戏

## 部署方式

### NAS 静态托管
- 群晖 Web Station
- Docker + Nginx
