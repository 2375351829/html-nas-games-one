# 饭局小游戏

一个为聚会设计的饭局游戏集合 Web 应用，**移动端优先设计**，支持摇骰子、猜数字等多种游戏，无需登录，开箱即用，让聚会更加有趣。

## 项目特点

- **极简设计**：单页面多游戏集成，无需跳转
- **无需登录**：所有用户匿名使用
- **本地存储**：使用浏览器 LocalStorage 实现历史记录
- **响应式布局**：**优先适配手机等移动设备**，同时兼容平板和桌面端
- **离线可用**：纯前端实现，无需联网
- **触屏优化**：专为移动设备触摸操作设计，操作区域大小合适
- **性能优化**：轻量设计，加载速度快，动画流畅

## 支持的游戏

- 摇骰子（支持自定义骰子数量）
- 猜数字（系统随机生成数字，提示大小）
- 预留扩展接口，可添加更多游戏

## 部署方式

### NAS 静态托管
- 群晖 Web Station
- Docker + Nginx
